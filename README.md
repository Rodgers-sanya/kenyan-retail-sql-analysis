# kenyan-retail-sql-analysis
SQL-based analysis of a Kenyan retail business to uncover sales, customer, product, salesperson, channel, and payment-method insights
# Kenyan Retail Sales Analysis Using SQL

## Project Overview

This project analyzes sales and customer data from a simulated
Kenyan retail business using MySQL.

## Business Objective

The objective is to identify:

- Revenue trends
- Customer spending patterns
- Top-performing products
- Product category performance
- Salesperson performance
- Sales channel performance
- Payment method behavior
- High-value customers

## Tools Used

- MySQL
- SQL

## Database

The database contains:

- 1,000 customers
- 500 products
- 5,000 orders
- 9,698 order-detail records

## How to Run the Project

### 1. Download the database

Download:

`retail_analysis_database.sql`

### 2. Open MySQL Workbench

Open MySQL Workbench and create a new SQL connection.

### 3. Import the database

Open the SQL file and execute it.

### 4. Select the database

USE kenyan_retail;

### 5. Run the analysis

Open the SQL files inside the `queries` folder and execute
the queries in MySQL Workbench.
